# ネイティブ依存の一覧(ビルドごと)

配布している開発ビルドに **入っているネイティブ部品** の一覧です。
ここに載っている部品は、JS から自由に使えます(ビルドし直しは不要)。
**ここに載っていないネイティブ部品は、今の開発ビルドでは動きません。** 使いたいときは土台担当に依頼してください。

- ネイティブ部品とは:iPhone 側のプログラム(Swift など)を含む部品。追加・削除・バージョン変更をすると、開発ビルドを作り直して全員の iPhone に入れ直す必要がある。
- JS だけの部品(例:`d3-force`、`@tanstack/react-query`)はここには載せない。`npx expo install` で各自追加してよい。
- 見分け方:`node_modules/<部品名>/` の中に `ios/` フォルダ、`*.podspec`、`expo-module.config.json` のどれかがあればネイティブ部品。迷ったら Claude Code に聞く。

### アプリの設定(`app.json`)

| 設定                   | 内容                                                                      |
| ---------------------- | ------------------------------------------------------------------------- |
| 写真ライブラリの許可   | 惑星・衛星づくりで写真を使う                                              |
| カメラの許可           | 好きなものを撮影する                                                      |
| マイクの許可           | 惑星の声を録音する(P1)                                                    |
| Bluetooth の許可       | すれ違いの検知                                                            |
| バックグラウンドモード | `bluetooth-central` / `bluetooth-peripheral`(アプリを閉じても BLE を使う) |

許可の文言やバックグラウンドモードを変えるのも、ビルドし直しが必要です。
