# ネイティブ依存の一覧(ビルドごと)

配布している開発ビルドに **入っているネイティブ部品** の一覧です。
ここに載っている部品は、JS から自由に使えます(ビルドし直しは不要)。
**ここに載っていないネイティブ部品は、今の開発ビルドでは動きません。** 使いたいときは土台担当に依頼してください。

- ネイティブ部品とは:iPhone 側のプログラム(Swift など)を含む部品。追加・削除・バージョン変更をすると、開発ビルドを作り直して全員の iPhone に入れ直す必要がある。
- JS だけの部品(例:`d3-force`、`@tanstack/react-query`)はここには載せない。`npx expo install` で各自追加してよい。
- 見分け方:`node_modules/<部品名>/` の中に `ios/` フォルダ、`*.podspec`、`expo-module.config.json` のどれかがあればネイティブ部品。迷ったら Claude Code に聞く。

## 3回目のビルドで追加するもの

2回目までの部品はすべてそのまま残り、次が加わります。

| 部品                                  | 何ができるか                                                          | 主に使う担当 |
| ------------------------------------- | --------------------------------------------------------------------- | ------------ |
| `modules/perigee-ble`(自作、iOS のみ) | BLE で自分の一時IDを発信し、近くの Perigee ユーザーの一時IDを受信する | 土台         |

- JS からは直接使わず、`@/features/encounter` から使う。ログイン後(惑星を作り終えたあと)に自動で検知が始まる。
- 2回目以前のビルドでは、このモジュールがないので検知は何もしない(アプリは落ちない)。ラボの「すれ違い検知(BLE)」に「入っていません」と出る。
- しくみ:決まったサービス UUID を広告する。相手がアプリを開いていれば広告の名前から一時IDを読み、バックグラウンドなら接続して一時IDを読む。
- `app.json` の変更は不要(Bluetooth の許可とバックグラウンドモードは1回目から入っている)。
- 動作確認は iPhone 2台が必要(シミュレータでは Bluetooth が使えない)。

## 2回目のビルドで追加するもの

1回目のビルドの部品はすべてそのまま残り、次の部品が加わります。

| 部品                             | バージョン | 何ができるか                                                              | 主に使う担当 |
| -------------------------------- | ---------- | ------------------------------------------------------------------------- | ------------ |
| `@six33/react-native-bg-removal` | ^1.3.4     | 写真から被写体を自動で切り抜く(背景が透明な PNG になる。衛星づくりで使う) | 写真         |

- 使い方:`removeBackground(写真の URI)` が、切り抜き後の PNG の URI を返す。周りの透明な余白は自動で削られる(`{ trim: false }` で残せる)。
- 内部では iOS の Vision(端末の AI)を使う。**iPhone の実機で iOS 17 以上** のときだけ切り抜ける。
- シミュレータ:切り抜かずに元の写真の URI をそのまま返す(警告が出る)。切り抜きの動作確認は実機で行う。
- iOS 16 以下:`REQUIRES_API_FALLBACK` というエラーになる。切り抜きなしで進める画面を用意しておくと安全。
- 被写体が見つからない写真:`Failed to create mask` というエラーになる。「切り抜けませんでした」の表示を出す。
- `app.json` の変更は不要(新しい許可やプラグインは要らない)。写真は今まで通り `expo-image-picker` で選ぶ。
- 色の取り出しは、1回目のビルドに入っている `react-native-image-colors` でできる(追加なし)。

### アプリの設定(`app.json`)

| 設定                   | 内容                                                                      |
| ---------------------- | ------------------------------------------------------------------------- |
| 写真ライブラリの許可   | 惑星・衛星づくりで写真を使う                                              |
| カメラの許可           | 好きなものを撮影する                                                      |
| マイクの許可           | 惑星の声を録音する(P1)                                                    |
| Bluetooth の許可       | すれ違いの検知                                                            |
| バックグラウンドモード | `bluetooth-central` / `bluetooth-peripheral`(アプリを閉じても BLE を使う) |

許可の文言やバックグラウンドモードを変えるのも、ビルドし直しが必要です。
